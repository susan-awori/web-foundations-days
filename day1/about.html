About QuickNotes

QuickNotes is a simple app for writing down your ideas fast. It helps you keep your thoughts in one place so you never forget them.

How to use QuickNotes

  1. Open QuickNotes.
  2. Type your note in the box.
  3. Save your note.

Features

  • Fast note taking
  • Simple, clean design
  • Keyboard shortcuts

Keyboard shortcuts

Shortcut Action
Ctrl + S Save note
Ctrl + N New note
