Web Development Foundations and System Design

Every website you visit is built from a few simple building blocks. Learning them helps you build small pages today and big systems tomorrow.

Web foundations

Three languages work together to make a web page:

  • HTML is the skeleton. It says what is on the page.
  • CSS is the clothes. It says how the page looks.
  • JavaScript is the brain. It says what the page does.

System design basics

System design is planning how the parts of an app fit together, like planning a city before building it.

  • Client: your browser, which asks for things.
  • Server: a computer that answers and sends things back.
  • Database: a big cupboard where information is stored.
  • API: a waiter who carries messages between the parts.
  • Cache: a small snack shelf for things people ask for often, so they arrive faster.

What happens when you open a website?

  1. You type an address in your browser.
  2. The browser asks a server for the page.
  3. The server may check the database for information.
  4. The server sends back HTML, CSS and JavaScript.
  5. Your browser shows you the page.
